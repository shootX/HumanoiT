# Humana Tasks CRM

CRM სისტემა პროექტების, ამოცანების, აქტივების და ბიზნეს პროცესების მართვისთვის.

## ტექნოლოგიები

- **Backend:** Laravel, PHP
- **Frontend:** React, Inertia.js, TypeScript, Tailwind CSS
- **ბაზა:** MySQL

## ფუნქციონალი

- **პროექტები** – შექმნა, რედაქტირება, ბიუჯეტი, მილსტოუნები
- **კონტაქტები** – ფიზიკური და იურიდიული პირები, Excel import (ქართული)
- **ამოცანები** – Task stages, კომენტარები, ჩეკლისტები
- **აქტივები** – აქტივების მართვა, კატეგორიები, ინსტრუმენტების ცალკე სია, ჩანაწერების გაერთიანება (merge), Excel export/import (ქართული)
- **ტექნიკა (Equipment)** – კონდიციონერები, გენერატორები ფილიალებში, გრაფიკი, QR კოდი, Excel export/import, bulk actions, მეტრიკები
- **ერთეულები (Units)** – ზომის ერთეულები (მაგ. კგ, ცალი), აქტივებზე და ინვოისის ხაზებზე
- **ინვოისები** – ინვოისების მართვა, ხაზზე ერთეული, ტექნიკის მოხმარება (ფრეონი, ბენზინი, წმენდა და ა.შ.), შესყიდვის XLS რეპორტიდან იმპორტი (სვეტი C – ერთეული)
- **კომპანიები და Workspaces** – მრავალკომპანიური რეჟიმი

### v1.7.1 (2026-03-29)

**SaaS რეჟიმი — ბაზის ცხრილების უსაფრთხო მიგრაციები**
- დაემატა safety migrations იმ შემთხვევისთვის, როცა ძველი მიგრაციები გაშვებული იყო `IS_SAAS=false`-ზე და ცხრილები რეალურად არ შეიქმნა:

**Task Report — მეტრიკები**
- `Total Tasks` = ყველა დავალება
- `Completed` = მხოლოდ `Done` სტატუსის მქონე დავალებები
- `Progress` = Done / Total %
- `Remaining` = Total - Done
- ფილტრების/ძებნის შეცვლისას სტატისტიკა ახლდება (AJAX პასუხში მოდის `stats`)

- რედაქტირებისას უკვე მინიჭებული used აქტივების შენარჩუნება

**ინვოისი – აქტივის ავტოკომპლეტი**
- 3+ სიმბოლოს აკრეფისას ჩნდება არსებული აქტივების ჩამონათვალი
- არჩევისას ნივთი უკავშირდება არსებულ asset-ს (დუბლიკატების თავიდან აცილება)
- ძებნა name და asset_code ველებით

**აქტივის ნახვა – შეძენის ინვოისები**
- ჩანს ყველა ინვოისის ჩამონათვალი, რომლიდანაც მოხდა შეძენა
- თითოეული ინვოისი ლინკით, რაოდენობით და თარიღით
